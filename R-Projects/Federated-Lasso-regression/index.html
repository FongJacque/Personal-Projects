Federated Lasso Regression

This project implements a decentralized, federated approach to Lasso regression using Python optimization techniques.

Project Components

  • 01_data_loading.py - Handles data preprocessing and ingestion pipelines.
  • 02_core_optimization_operators.py - Contains mathematical functions for Lasso optimization.
  • 03_hyperparameter_protocol.py - Manages regularization parameter settings.
  • 04_synchronous_global_loop.py - Coordinates the federated aggregation across simulated nodes.

How to Run

Execute the main controller script in your terminal to see the simulation run:

python run_project.py
